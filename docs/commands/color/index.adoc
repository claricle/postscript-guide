== Color

Commands for color operations in PostScript.

== Overview

This category contains PostScript operators for color.

== Commands

[cols="1,3"]
|===
| Command | Description

| link:/commands/references/setcolorspace/[`setcolorspace`]
| Select the current color space (Level 2)

| link:/commands/references/setcolor/[`setcolor`]
| Set the color in the current color space (Level 2)

| link:/commands/references/makepattern/[`makepattern`]
| Create a pattern instance from a dictionary and matrix (Level 2)

| link:/commands/references/setpattern/[`setpattern`]
| Select a pattern as the current painting color (Level 2)

| link:/commands/references/setblackgeneration/[`setblackgeneration`]
| Set black generation for RGB-to-CMYK conversion (Level 2)

| link:/commands/references/setundercolorremoval/[`setundercolorremoval`]
| Set undercolor removal for RGB-to-CMYK conversion (Level 2)
|===
