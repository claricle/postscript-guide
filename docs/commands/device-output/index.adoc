== Device Output

Commands for device output operations in PostScript.

== Overview

This category contains PostScript operators for device output.

== Commands

[cols="1,3"]
|===
| Command | Description

| link:{site-baseurl}/commands/references/showpage/[`showpage`]
| Output the page and reinitialize graphics state (Level 1)

| link:{site-baseurl}/commands/references/copypage/[`copypage`]
| Output the page without reinitializing graphics state (Level 1; page retention changes in Level 3)

| link:{site-baseurl}/commands/references/nulldevice/[`nulldevice`]
| Discard graphical output (Level 1)

| link:{site-baseurl}/commands/references/setpagedevice/[`setpagedevice`]
| Request page device configuration changes (Level 2)

| link:{site-baseurl}/commands/references/currentpagedevice/[`currentpagedevice`]
| Read the current page device dictionary (Level 2)
|===
