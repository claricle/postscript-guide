== Device Output

Commands for device output operations in PostScript.

== Overview

This category contains PostScript operators for device output.

== Commands

[cols="1,3"]
|===
| Command | Description

| link:/commands/references/showpage/[`showpage`]
| Output the page and reinitialize graphics state (Level 1)

| link:/commands/references/copypage/[`copypage`]
| Output the page without reinitializing graphics state (Level 1; page retention changes in Level 3)

| link:/commands/references/nulldevice/[`nulldevice`]
| Discard graphical output (Level 1)
|===
