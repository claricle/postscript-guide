= nulldevice

Install an output device that discards graphical marks.

== Description

`nulldevice` selects a device with no physical output or raster storage. Drawing and font operations still execute, but their marks are discarded; `showpage` and `copypage` produce no output.

The null device has an identity default transformation matrix and a degenerate clipping path at the origin. Bracket its use with `gsave` and `grestore` to restore the previous device and graphics state. It is useful for exercising graphics or font operations without producing a page.

== Syntax

[source,postscript]
----
- nulldevice -
----

=== Stack Effect

Stack entries are shown from bottom to top; earlier operands are unchanged.

[cols="1,3"]
|===
|State |Operand stack

|Before
|No operands required

|After
|Unchanged
|===

== Examples

[source,postscript]
----
gsave
  nulldevice
  /Helvetica findfont 12 scalefont setfont
  0 0 moveto (Measure without output) show
  currentpoint % Leaves the final x and y coordinates
grestore
----
