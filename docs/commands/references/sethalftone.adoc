== sethalftone

Installs a halftone dictionary in the graphics state.

=== Syntax

----
dict sethalftone → –
----

=== Stack Effects

Earlier operands remain unchanged. Stack level 0 is the top of the stack.

.Before
[cols="1,3"]
|===
| Level | Object

| 0
| `dict` (halftone definition)

|===

.After
[cols="1,3"]
|===
| Level | Object

| (none)
| Halftone installed for subsequent rendering

|===

=== Description

`sethalftone` selects how continuous color values are represented by the output device's available marks. The dictionary's `HalftoneType` determines its required entries.

A type 1 dictionary describes a spot-function screen using `Frequency`, `Angle`, and `SpotFunction`. The spot function consumes two coordinates in the range -1 to 1 and returns a value in that range to order the screen's dots.

The effect depends on device resolution and rendering behavior. Use device defaults for portable output, or isolate a deliberate screen change with `gsave` and `grestore`.

=== PostScript Level

*Level 2* and later

=== Examples

.Installing a simple spot-function screen
[source,postscript]
----
gsave
  << /HalftoneType 1
     /Frequency 60
     /Angle 45
     /SpotFunction { dup mul exch dup mul add 1 exch sub }
  >> sethalftone
  0.5 setgray
  20 20 100 50 rectfill
grestore
----

=== Error Conditions

Common errors include the following; procedures and device operations can raise additional errors.

[cols="1,3"]
|===
| Error | Condition

| `stackunderflow`
| The halftone dictionary or an operand required by its procedure is missing.

| `typecheck`
| The operand or a halftone entry has the wrong type.

| `rangecheck`
| A halftone value or spot-function result is outside its valid range.

| `undefined`
| A required dictionary entry is missing or the painting context forbids this operator.

| `limitcheck`
| The screen exceeds an implementation limit.
|===
