= false

Push the boolean value `false`.

== Description

Executing the name `false` pushes the boolean value `false` onto the operand stack. It takes no operands. Strictly speaking, this is a name in `systemdict` associated with a boolean object, rather than an operator.

Booleans are distinct from integers: `true` is not the number 1, and `false` is not the number 0. Use booleans as conditions for `if` and `ifelse`.

== Syntax

[source,postscript]
----
- false false
----

=== Stack Effect

Stack entries are shown from bottom to top; earlier operands are unchanged.

[cols="1,3"]
|===
|State |Operand stack

|Before
|No operands required

|After
|`false`
|===

== Examples

[source,postscript]
----
false type     % booleantype
false not      % true
false { (yes) } { (no) } ifelse % (no)
----

== Error Conditions

`stackoverflow`::
The operand stack has no room for another object.
