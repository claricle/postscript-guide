== makepattern

Creates a pattern instance from a pattern dictionary and matrix.

=== Syntax

----
dict matrix makepattern → pattern
----

=== Stack Effects

Earlier operands remain unchanged. Stack level 0 is the top of the stack.

.Before
[cols="1,3"]
|===
| Level | Object

| 1
| `dict` (pattern definition)

| 0
| `matrix` (pattern-space transformation)

|===

.After
[cols="1,3"]
|===
| Level | Object

| 0
| `pattern` (read-only pattern instance)

|===

=== Description

`makepattern` combines a pattern definition with a transformation and returns a pattern instance suitable for `setpattern` or `setcolor`. It does not select the pattern or paint anything by itself.

A tiling pattern uses `PatternType 1`, a bounding box, tile spacing, and a `PaintProc`. `PaintType 1` supplies its own colors; `PaintType 2` uses a color supplied when the pattern is selected. Shading patterns use `PatternType 2` and require Level 3.

The supplied matrix maps pattern space into the user space in effect at creation. The resulting instance retains that placement, so create it under the intended transformation.

=== PostScript Level

*Level 2* and later

=== Examples

.Creating and painting a colored tile
[source,postscript]
----
gsave
  << /PatternType 1 /PaintType 1 /TilingType 1
     /BBox [0 0 8 8] /XStep 8 /YStep 8
     /PaintProc {
       pop
       0.2 0.4 0.8 setrgbcolor
       0 0 4 4 rectfill
     }
  >> matrix makepattern
  setpattern
  20 20 80 40 rectfill
grestore
----

=== Error Conditions

Common errors include the following; procedures and device operations can raise additional errors.

[cols="1,3"]
|===
| Error | Condition

| `stackunderflow`
| The dictionary or matrix operand is missing.

| `typecheck`
| An operand or dictionary entry has the wrong type.

| `rangecheck`
| A pattern parameter has an invalid value.

| `undefined`
| A required pattern entry is missing.

| `limitcheck`
| The pattern exceeds an implementation limit.
|===
